# Manar Hamdan | Portfolio

موقع بورتفوليو بـ HTML و CSS و JavaScript بدون أي frameworks.

## الملفات
- `index.html` الهيكل
- `style.css` الألوان والتصميم (الوضع الفاتح/الداكن، ألوان التمييز، RTL، الموبايل)
- `script.js` الخلفية التفاعلية (العصبونات)، قاموس الترجمة، المشاريع، النموذج
- `assets/` الصورة والـ CV

## تعديل روابط GitHub للمشاريع
افتحي `script.js` وابحثي عن المصفوفة `projects`. كل مشروع فيه `repo: PROFILE_URL`،
بدّليها برابط الريبو الخاص بالمشروع، مثلاً:

    repo: 'https://github.com/manarhamdan222-art/pharmachain',

## نشر الموقع مجانًا
ارفعي الملفات لريبو على GitHub ثم Settings > Pages > Deploy from a branch > main > /root.
